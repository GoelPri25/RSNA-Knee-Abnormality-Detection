## 2. The best single model: Exp 1e

**Checkpoint:** `weights_swa21_25.pt` (sha256 `cb2382ec…`, 97 MB) in Kaggle dataset
**`tumis001/rsna-d96-r50-exp1e-pertarget-fold0`** (with the timm 1.0.29 wheel for offline install).
Inference kernel: **`tumis001/rsna-d96-r50-exp1e-pertarget-submission`**
(source `kaggle/submission_kernels/d96_r50_exp1e_pertarget_submission/submission.py`; it rebuilds the d96 input from
DICOM inside the kernel, so it is the reference implementation of the full test-time pipeline).

**Recipe** (`scripts/coatnet_d96_runner.py`, `D96_PHASE=r50_pertarget`):

| Part | Setting |
|---|---|
| Input (d96 cache) | 96 slices over 5 series slots (sagittal fluid 26, sagittal non-fluid 22, coronal fluid 18, coronal non-fluid 12, axial 18); 384 px over a 140 mm field; per-series 2/98 % intensity window; uint8 |
| Windows | 3 adjacent slices = 3 channels; training: 16 stratified random windows per study; evaluation: 94 evenly spaced |
| Backbone | `resnet50.tv_in1k` (timm) |
| Head | public notebook's "Raptor": GAP per window → LayerNorm → per-finding attention over windows (Linear 2048→256, tanh, dropout 0.2, →12; softmax over windows per finding) → per-finding linear classifier |
| Labels / loss | per-target labels (sha `d40803d0…`), every cell weight 1.0; weighted BCE |
| Optimiser | AdamW, 1e-4 backbone / 1e-3 head, wd 0.05, grad clip 1.0, bf16 |
| Schedule | 25 epochs: 1 warm-up epoch, cosine to a 1% floor |
| Batch | 2 studies × 16 windows per step, 4 accumulation steps (8 studies per update) |
| Augmentation | anatomical L/R mirror (p 0.5), ±10° rotation, ±10% scale, ±6% shift, gamma and gain jitter |
| Final weights | weight average of epochs 21–25, BatchNorm recomputed on 256 training studies |
| Inference | centre 320 crop (no resize), 94 windows, no TTA |
| Seed / fold | 2026; train on folds 1–4, validate on fold 0 |

Fold-0 scores: 10-target 0.9073 (seed 2027: 0.9097), 12-target 0.9037, clear-band 6-target 0.9719, gold-58 0.905.

## 5. How to train / reproduce

1. Attach the four `rsna-coatnet-d96-cache-shard-*` kernel outputs (they are the d96 cache; no DICOM needed).
2. Run `scripts/coatnet_d96_runner.py` with `D96_CACHE` = cache dir, `D96_ASSETS` = labels/folds dir,
   `D96_OUT` = output dir, `D96_PHASE=r50_pertarget`. Requirements: torch, timm 1.0.29, numpy.
3. On an H100 a 25-epoch run takes ~40 min (~88 s/epoch). It was run on a personal Modal account
   (`scripts/modal_coatnet_d96.py`), which is not shareable; with your own Modal account the launcher works as is
   after `modal token new`. On Kaggle T4 expect roughly 10× slower (several hours, within the 12 h limit).
4. Score with `python scripts/audit_d96_native.py <root> <run_dir_name> <label>` against the saved
   `val_swa.json`.

## 6. What the evidence says (read before choosing an idea)

**Readouts.** The headline fold-0 macro does **not** track the LB across our 7 submitted singles (Pearson ≈ −0.1);
the **clear-band** AUC (moderate+ positives vs confident negatives; 6 targets with ≥ 20 clear positives) does
(+0.94 over 7 points). Reason (2-conv): the fold-0 ruler counts report-"mild" findings positive (P 0.89), the
competition labels treat them as a coin flip (0.56 on gold-58). Seed spread: ~0.002 macro, up to 0.006 per target,
±0.002 on the LB.

**Tried, no gain over 1e** (details in the ledger): cross-window transformer (2a), per-plane heads (2c/2d),
native slice density (4b: fold-0 +0.003, all in the mild band, weak clear band), plane routing (2-route), label
re-valuing (3a, 3b), self-supervised pretraining on our MRI (5a), OrthoDiffusion external backbones (5b-probe),
SWA with a cyclic tail (6a), series-allocated windows (6b: MCL +0.014, but OA / meniscus / contusion fall),
cosine+EMA, soups, ensemble re-weighting.

**What moved things:** recipe (v1 224 px → d96 384 px with per-finding window attention, +0.008 LB), training
long enough (1b), and your per-target label choice (1e, about +0.002 over D2 on two-seed LB means).

**Open directions:**
- **v3 architecture**: finding-specific spatial pooling inside each window (instead of plain averaging) at
  output stride 16; under review — see the two v3 docs.
- **Exp 7, labels**: replace the ~0.5 targets of report-ambiguous cells (effusion 1,257, PF OA 913, medial OA 725,
  MCL 497 in the training folds) with strictly out-of-fold image predictions. On gold-58 the image models separate
  host labels within report-ambiguous cells at AUC ~0.78 (development check; script not yet committed).
- **Exp 6, report-derived auxiliary heads**: 40 extra findings (horn, compartment, bone-marrow-oedema location,
  tendons...) extracted by an LLM inside Kaggle; vLLM on T4 was too slow (3 reports/min); a transformers-based
  extraction would take ~3–4 h of quota. Kernel `rsna-exp6-aux-findings-extraction`.

## 7. Project rules we have kept

- Validation (fold-0) labels and gold-58 labels are never changed; gold is never used for training or selection.
- Model predictions may shape **training** labels only strictly out-of-fold.
- Raw reports and DICOM never leave Kaggle (no external LLM APIs on them).
- No OAI data. No all-data retrains until a single model exceeds 0.95 on the public LB.
- Every experiment is pre-registered in the ledger (change, primary readout, PASS rule) before launch.
