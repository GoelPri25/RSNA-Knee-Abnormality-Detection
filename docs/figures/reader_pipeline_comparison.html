The model head, drawn

What each step bought, and what 2a is betting on

0.925 → 1c: measured

  • Fold 0 +0.0111 [+0.0046, +0.0175], every bootstrap better; LB +0.008; gold-58 +0.028.
  • Same backbone and labels, so the gain is the recipe: more slices over the full stack, ~1.7× finer pixels, learned pooling, and a schedule that does not pick on fold 0.
  • Largest per-target gains on fold 0: ACL +0.030, medial OA +0.021, lateral OA +0.021, lateral meniscus +0.019, synovitis +0.018.
  • One loss: MCL −0.027 on fold 0 (0.806, the weakest target), though gold MCL rose to 0.934.

1c → 2a: hypothesis

  • Lateral OA is still weak (fold 0 0.871, gold 0.83). Today's tests ruled out the evaluation crop (Exp 1d) and the label set (Exp 1e, which made gold lateral OA worse).
  • Radiologists confirm compartment OA and MCL injury by matching coronal and sagittal views of the same compartment. 1c cannot relate two windows, and does not know which compartment a sagittal slice is in.
  • 2a adds exactly those two things and nothing else, so a change in fold 0 can be attributed to them.

Pre-registered rule for 2a

  • Primary: average of epochs 21–25, 94 windows, no TTA, Steven-v4 fold-0 confident cells.
  • Pass if 2a beats 1c (0.9074) by ≥ +0.003 with ≥ 90% of 2,000 paired bootstraps better.
  • Reported, not used to decide: lateral OA, MCL, PF OA per target; gold-58; a 6 × 16-window readout.

Known risk: training sees 16 windows and evaluation sees 94, so the transformer meets a longer sequence at test time. The 16-window readout shows whether that costs anything.

Checks before launch

  • Coverage of DICOM geometry and knee side in the d96 manifests; slices without them fall back to their relative index within the slot.
  • Position is anatomical (medial stays medial), so the left/right mirror augmentation does not contradict it.
  • CPU preflight: at initialisation 2a's outputs equal 1c's for the same weights, and one 94-window forward pass is finite.
