# HPO-v1 sequence-conditioned CNN

The sequence-conditioned reader adds one small branch to the ResNet-34 CNN: each 2.5D window receives its series' official anatomical plane and fluid-sensitive flag through a zero-initialized, target-specific logit correction. There is no self-attention layer. The seven categories are sagittal/coronal/axial crossed with fluid-sensitive yes/no, plus unknown metadata. `Fat_Suppression` is not supplied separately because it duplicates `Fluid_Sensitive` in this dataset.

The correction has only 84 parameters (7 categories × 12 findings) and starts at exactly zero, so it initially leaves image logits unchanged. For each window, it adds the learned acquisition-specific offset to the ResNet per-finding logits; target-specific top-10% window pooling then runs unchanged. It can learn per-finding evidence adjustments by acquisition type while preserving the image pathway.

The paired from-scratch experiment initializes ResNet-34 from the same ImageNet weights as the 0.918 baseline, rather than from the trained knee-model checkpoint. This tests whether the sequence branch helps while the model learns the task from the beginning. The existing 0.918 run is the baseline comparison; data, labels, fold assignment, seed, and training controls match, with sequence conditioning as the architecture change.

Everything else stays fixed: 224 × 224 images from a 140 mm physical crop, three neighboring slices plus three support-mask channels, uniform 24-window study sampling, HPO-v1 labels including the 281 train-only additions, the same fixed fold-0 825-study report validation scored against Steven v4, batch size 8, learning rate 3e-4, weight decay 0.03, ReduceLROnPlateau on validation BCE, and AUC-based early stopping (patience 8, min delta 0.0005). The 58 official gold-label studies remain locked and are not loaded.

Run the matched from-scratch experiment with `python scripts/run_modal_personal_sequence_from_scratch.py`. The launcher uses only `~/.config/rsna/modal-personal.env` and starts a detached Modal task with `modal run --detach`; the local entrypoint spawns the training function and exits instead of holding its call open. Checkpoints/logs/metrics publish every two epochs to private Kaggle dataset `tumis001/rsna-hpo-blend-sequence-from-scratch-fold0`. It reuses the existing Modal derived-cache volume and does not transfer raw DICOMs. The warm-start variant is launched separately with `python scripts/run_modal_personal_sequence_conditioned.py` and writes to its own dataset.
